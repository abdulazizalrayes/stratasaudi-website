# CEO Agent Creation Policy

Every new Strata Saudi agent must declare:

- business owner
- business objective
- job-to-be-done
- risk level
- workload volume
- reasoning depth
- coding intensity
- multilingual requirement
- data sensitivity
- lane
- adapter
- provider/model
- fallback
- escalation path
- required tools
- approval requirement
- KPI ownership

Hard rules:

- No new agent defaults to `codex` or `claude_code` without explicit written justification.
- Executive title alone is not a premium-adapter justification.
- Strategy work and utility work should be split into separate agents.
- Routine operations default to `opencode`.
- Browser access is denied unless the agent is explicitly allowlisted.
- Vague or duplicative agent purposes should be rejected.
- Do not preserve or reintroduce stale human-hiring workflow logic for routine Strata agent creation, updates, or syncs.
- Default to direct create, update, and sync inside the live Strata Paperclip company unless the board explicitly asks for a formal exception review.
