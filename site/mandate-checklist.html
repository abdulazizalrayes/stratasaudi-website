Mandate screening

Mandate checklist for serious Saudi project exposure.

This checklist is intended to help sophisticated counterparties frame the mandate, urgency, evidence position, and decision need before opening a confidential Strata review.

Start confidential enquiry
1. Counterparty type
  • Foreign EPC contractor
  • Foreign developer or sponsor
  • International law firm
  • Investment group, board, or committee
2. Mandate type
  • Pre-contract risk review
  • Project risk oversight
  • Pre-litigation technical advisory
  • Independent technical opinion
  • Vendor or supply-chain risk assessment
  • Board or investment committee briefing
3. Exposure snapshot
  • Project name
  • Stage
  • Contract form
  • Value band
  • Key stress signal
4. Urgency
  • Immediate
  • This month
  • This quarter
  • Monitoring
5. Evidence readiness
  • Core contracts available
  • Notices available
  • Chronology available
  • Technical records available
  • Vendor data available
6. Decision need
  • What decision is pending?
  • What downside are you trying to avoid?
  • What would a useful advisory outcome look like?

When to use this

Use this checklist when the matter is commercially significant, technically sensitive, or moving toward a pressure point that requires disciplined Saudi project judgment.

What happens next

  • We review fit, urgency, and conflict posture.
  • Qualified matters are routed into Strata’s mandate review path.
  • Where necessary, we request the minimum additional context required for responsible assessment.
